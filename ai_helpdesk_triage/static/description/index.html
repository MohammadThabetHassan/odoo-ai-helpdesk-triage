AI Helpdesk Triage Agent

Human-reviewed Anthropic triage for Odoo support tickets. The AI classifies, prioritizes, routes, drafts a reply, explains reasoning, and records confidence and cost telemetry. Humans remain responsible for assignment, progress, resolution, and closure.

Structured AI Output

Uses Anthropic tool-use JSON schema output with validation, corrective retry, and safe fallback when model output is invalid.

Governed Autonomy

Configurable confidence thresholds decide whether to route, recommend review, or keep the ticket New for human triage.

Audit and Cost

Every triage posts a chatter summary and stores input tokens, output tokens, model name, and estimated ticket cost.

Evaluation Ready

Ships with a golden dataset, evaluation script, correction capture model, and dashboard for future dataset improvements.

Workflow

New to AI Triaged is the only AI-driven transition. Every later transition is a human button click.

Privacy

Optional PII redaction masks obvious emails and phone-like values before API calls. The README documents exactly what leaves the server and deployment considerations for UAE PDPL/GDPR-style controls.
